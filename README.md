# AlquiCar
Aplicación react native de alquiler de coches

## Dependencias:
- Para correr y construir este proyecto es necesario el framework expo y node.js
```bash 
npm install
```
```bash 
npm install -g expo-dev-cli
```
- Para realizar las peticiones al servidor, el backend del proyecto debe estar activo en el puerto 3000 del localhost
